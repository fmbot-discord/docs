# Youtube commands

### .youtube (`.yt`) { data-slash="/youtube" }

Gets the Youtube link for the song you're currently listening to, or the one you're searching for.

Youtube embeds will be hidden if the user requesting does not have the 'Embed Links' permission.

Options:
{ .cmd-slash }

* Search - What to search for. Defaults to what you're currently listening to
{ .cmd-slash }
* Private - Only show the response to you
{ .cmd-slash }

!!! note cmd-text "Examples"
    `.yt`

    `.youtube`

    `.yt Rick Astley Never Gonna Give You Up`

    `.youtube Hi Stranger`

!!! note cmd-slash "Examples"
    `/youtube`

    `/youtube search:Rick Astley Never Gonna Give You Up`

    `/youtube search:Hi Stranger private:True`
